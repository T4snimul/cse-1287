# CSE 1287

This repository contains the solution to the programming problems that appeared in the semester final exams.

## How to Run

Clone this repository

```bash
git clone https://github.com/t4snimul/cse-1287.git
```

### For Windows

Run the following command in PowerShell

```ps1
.\run.ps1 .\year\1-a-problem.c
```

Example

```ps1
.\run.ps1 .\2024\5-b-factorial.c
```
